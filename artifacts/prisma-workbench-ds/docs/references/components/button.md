# Button family

## Source evidence

- `artifacts/litmatrix/src/App.tsx`: header actions and workflow navigation actions.
- `artifacts/litmatrix/src/components/MethodsProtocol.tsx`: generate, save,
  and reset actions.
- `artifacts/litmatrix/src/components/FullReviewReport.tsx`: abstract and
  manuscript actions.

## Extracted behavior and visual rules

Primary actions use indigo with white text. Secondary actions use white or
slate surfaces with a slate border. Destructive actions use rose/red sparingly.
Buttons are compact, rounded, mono-labelled, and show a clear disabled state
when prerequisites are incomplete.
